# Running the Scripts

This project contains several Python scripts. Here's how to run each one.

## Setup

Make sure you have Python 3.10+ installed, then install the required packages:

```bash
python -m pip install requests pytest
```

## Scripts

### hello.py
Prints a name, college, and major.
```bash
python hello.py
```

### calculator.py
Demonstrates basic arithmetic functions.
```bash
python calculator.py
```

### loops.py
Demonstrates for and while loops.
```bash
python loops.py
```

### lists_dicts.py
Demonstrates lists, tuples, and dictionaries.
```bash
python lists_dicts.py
```

### string_utils.py
Contains string utility functions (reverse, count vowels, palindrome check).
```bash
python string_utils.py
```

### file_manager.py
Reads sample.txt, counts the words, and writes the result to results.txt.
```bash
python file_manager.py
```

### weather_api.py
Fetches and displays current weather for a city using the OpenWeatherMap API.
See [api-usage.md](api-usage.md) for setup instructions.
```bash
python weather_api.py
```
